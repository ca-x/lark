# Vinyls reference artwork

Source: https://vinyls.sandheep.xyz by Sandheep (Sandy), retrieved 2026-09-08.

`deck.svg`, `fixtures.svg`, `record.svg`, and `tonearm.svg` are static SVG artwork extracted from the reference's rendered deck layers at the user's explicit request to retain the original tonearm material. Original gradients, paths, grain filters and mechanical details are retained. Each image includes its own material definitions so it works as a local, self-contained image. Runtime transforms, page classes and pointer styles were removed; the record viewBox is cropped around its centre.

The source page does not declare a license for these assets. This provenance note does not relicense them. Lark's React interaction and CSS integration are implemented separately. No reference music, album artwork, JavaScript application code or YouTube playback integration is included.
